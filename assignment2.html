Attendance Management App

A no-code Android attendance management application developed using MIT App Inventor, Google Forms, and Google Sheets for automated attendance tracking.

01

Attendance Management App

The Attendance Management App is a simple Android application designed to collect and manage attendance efficiently.

The application was developed using MIT App Inventor and integrated with Google Forms and Google Sheets to automatically record attendance information.

MIT App Inventor Google Forms Google Sheets

Attendance Management App

02

About MIT App Inventor

MIT App Inventor is a web-based platform that allows anyone to create Android applications using a simple drag-and-drop interface.

It is designed for people with little or no programming experience and is widely used for educational and prototyping purposes.

With MIT App Inventor, developers can quickly design the application interface and use visual blocks to control application logic, making app development fast, accessible, and beginner-friendly.

How the App Works

01

Open the Application

The user opens the application and taps the "Open Attendance Form" button.

02

Open Attendance Form

The Google Form opens inside the application using the WebViewer component.

03

Enter Attendance Details

The user enters the name, date, and attendance status such as Present, Absent, or Late.

04

Submit the Form

The submitted information is automatically transferred to the linked Google Sheet.

05

Store Attendance Data

Google Sheets records the attendance details along with the submission timestamp.

05

The first step was to create a Google Form for collecting attendance information.

  • Add fields for Name, Date, and Status.
  • Include Present, Absent, and Late options.
  • Link the form to a Google Sheet.

Add Logic with Blocks

The application logic was created using MIT App Inventor's visual block-based programming environment. Instead of writing traditional programming code, blocks were connected together to define how the application behaves when the user interacts with it.

01

Button Interaction

A button was configured to allow the user to open the attendance form from the application.

02

WebViewer

The WebViewer component was used to load the Google Form directly inside the application.

03

Form Integration

The Google Form link was connected to the application so users could submit attendance without leaving the app.

04

Data Flow

Submitted attendance information was transferred to the linked Google Sheet for storage and tracking.

08

Submit and Store Attendance

Once the user submits the attendance form, the information is automatically transferred to the linked Google Sheet.

The sheet stores the attendance details together with the timestamp, allowing the records to be easily monitored and managed.
